# TSK-025: Unmanage, adopt and tombstones

## Description

Add `wskit unmanage UNIT` and `wskit adopt UNIT`: unmanage removes active membership and keeps history and point references as a tombstone with an accepted match exception; adopt transfers ownership back, using the draft-and-stop path for root units and fleet configs.

## Outcome

After this merges, a person can take a unit out of the kit's hands, or give one back, without changing the machine.

## Deliverables

- commands and records: `internal/engine/`, `internal/cli/`

## Acceptance Criteria

- AC-1 Unmanage and adopt change records only, never the machine; evidence: tests
- AC-2 A revert to baseline passes after adopt and after unmanage; evidence: fixture tests
- AC-3 Adopt for a root unit or a fleet config drafts the change and stops; evidence: tests
