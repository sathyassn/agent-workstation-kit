# TSK-003: CI for Go on Linux and macOS

## Description

Add CI jobs that run gofmt, goimports, go vet, golangci-lint with `.golangci.yml`, go test and govulncheck on Ubuntu and macOS runners, with every action pinned by commit SHA, and add the Go targets to `.codeflow/test-config.json`.

## Outcome

After this merges, every PR that touches Go is linted, tested and scanned for known vulnerabilities on both OSes.

## Deliverables

- workflow: `.github/workflows/go.yml`
- gate targets: `.codeflow/test-config.json`

## Acceptance Criteria

- AC-1 When a PR adds a lint finding, a failing test or a known-vulnerable dependency, CI fails; evidence: a CI run on a planted case
- AC-2 Every action is pinned by commit SHA; evidence: the repository check
- AC-3 `codeflow test --mode full` runs the Go targets and the kit gates; evidence: the gate artefact
- AC-4 A contributor opens a pull request and sees `Go (ubuntu-24.04)` and `Go (macos-latest)` report on their change; evidence: the CI run on this pull request (journey)
