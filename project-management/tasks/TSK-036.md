# TSK-036: Agent manual lessons and the plain-writing rule

## Description

Bring two sets of contributor guidance into the repository's own instructions. First, the operator's plain-writing rule from PR #3, rebased onto today's files: the agent manual, CONTRIBUTING, the pull-request template, the setup skill and the changelog. Second, the delivery lessons from the pilot work that a planning PR could not carry: renaming Orca worker branches before the first commit, each task PR carrying its own completion record with a matching Reviews row, bringing PRs current without force pushes, fast-forwarding the root checkout after merges, the first CodeFlow PR failing its gates by design, and the Go version line in `registry/tools.toml` as a security pin.

## Outcome

After this merges, an agent or contributor working in this repository finds the writing rule and the delivery lessons where they already look: `AGENTS.md`, CONTRIBUTING and the PR template.

- `AGENTS.md` section 7 and a writing rule
