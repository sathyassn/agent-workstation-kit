# TSK-038: mDNS as a firewall setting

## Description

Add an `mdns` setting to the firewall unit so multicast DNS on 5353/udp is an explicit, previewed choice instead of an open port that the host audit reports as a failure. Values: `off`, `on`, or `on-interfaces` with a list of trusted LAN interfaces; the default is `off` on work machines, shown in `plan` with its reason. On Linux the unit manages the UFW rule and avahi's configuration. On macOS, where mDNSResponder cannot be turned off without breaking the system, the unit applies the Application Firewall equivalent and states the gap. Non-goal: printer or AirPlay setup.

## Outcome

After this merges, a person choosing firewall settings sees what mDNS allows and what stops working when it is off, and the doctor and host audit report the chosen value as approved.

## Deliverables

- setting, apply, verify and revert: `internal/units/firewall/` (Linux UFW and avahi; macOS Application Firewall)
- preset default and its reason: `registry/presets.toml`, `registry/sources.toml`
- capability row: ADR 0005 section 8a (already added by the planning change)
- tests and docs: unit tests per value and OS, the firewall unit's docs page, `CHANGELOG.md`

## Acceptance Criteria

- AC-1 `mdns` accepts `off`, `on` and `on-interfaces` with a non-empty list of interface names; any other value, an empty list, or the mesh-VPN interface in the list is refused at validation with the field path; evidence: tests (serves EPC-015 AC-11)
- AC-2 On Linux, `off` removes any kit rule for 5353/udp and sets avahi to not publish; `on-interfaces` allows 5353/udp only on the named interfaces and sets avahi `allow-interfaces` to the same list; every value sets `publish-workstation=no`; apply then revert restores the earlier UFW rules and avahi file byte for byte; evidence: tests with fake UFW and avahi state (serves EPC-015 AC-11)
- AC-3 On macOS, `off` turns on Application Firewall stealth mode and blocks incoming connections for Bonjour-advertising services, `plan` states that mDNSResponder stays on (the recorded gap), and revert restores the earlier Application Firewall state; evidence: tests with a fake `socketfilterfw` (serves EPC-015 AC-11)
- AC-4 The default is `off` on work machines, shown in `plan` with its reason and source, and `plan` lists what stops working when off: automatic printer, AirPlay and cast discovery; printers added by hand keep working; evidence: tests and the plan text
- AC-5 The doctor and host audit report the configured value as approved, and an open 5353/udp that the setting does not explain still fails; evidence: tests (serves EPC-022 AC-8)
- AC-6 A person previews the firewall unit on a Linux host with `on-interfaces` set to one LAN interface, sees the rule, the avahi change and what stays off, applies it and reverts it; evidence: the test transcript (journey)
