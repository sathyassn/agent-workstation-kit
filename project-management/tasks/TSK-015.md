# TSK-015: Output modes and the plain and JSON front ends

## Description

Build `internal/ui` with the mode precedence (JSON, plain, terminal UI), JSON results on standard output and JSON-line events on standard error, plain output with no prompts, and accessibility rules (T1d).

## Outcome

After this merges, agents get stable JSON and plain output with no prompts, whatever terminal they run in.

## Deliverables

- front ends: `internal/ui/`
- snapshots: `testdata/ui/`

## Acceptance Criteria

- AC-1 Mode precedence and stream framing match SPC-001; evidence: snapshot tests
- AC-2 NO_COLOR, TERM=dumb and non-terminal output give no colour, animation or prompt; evidence: tests
- AC-3 Tool output never reaches the terminal in JSON or plain mode; evidence: tests
