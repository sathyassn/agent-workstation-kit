# TSK-008: Quiet findings, obfuscation checks and self-scan

## Description

Print only file, line and rule for each finding; catch zero-padded octets, glued prefixes and partial private prefixes; and scan the rule file and the scanner's own tests, allowing only listed synthetic values.

## Outcome

After this merges, CI logs never show what the public scan found, and common obfuscations are caught.

## Deliverables

- scanner: `tests/check_public_release.py`
- tests: `tests/`

## Acceptance Criteria

- AC-1 A finding's output holds file, line and rule only; evidence: a test that checks the output
- AC-2 Each obfuscation case is flagged; evidence: one test per case
- AC-3 The rule file and the scanner tests are scanned; evidence: a test
