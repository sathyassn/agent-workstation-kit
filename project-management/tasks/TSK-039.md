# TSK-039: Generated man pages for wskit

## Description

Generate a `wskit` man page from the Cobra command tree, as ADR 0005 section 2b asks for beside the shell completions. TSK-009 builds the command tree and the completions and leaves the man page to this task. The generator is Cobra's own `cobra/doc` package, the choice section 2b records; it brings `github.com/cpuguy83/go-md2man/v2`, which needs a `registry/tools.toml` entry with its pin and source before it becomes a direct dependency. Non-goal: hand-written manual sections beyond what the command tree and its help text give.

## Outcome

After this merges, a person on Linux or macOS reads `man wskit` for the installed version, and CI fails when the page is stale against the command tree.

## Deliverables

- generator and its pin: `cobra/doc` with `go-md2man` in `registry/tools.toml` and `go.mod`, run by a `go generate` step beside the CLI in `internal/cli/`
- generated page: `docs/reference/man/wskit.1` (provisional; the staging layout in ADR 0005 section 9 decides where the installed copy goes)
- staleness check: the generated-code check from TSK-005
- docs and changelog: `docs/reference/`, `CHANGELOG.md`

## Acceptance Criteria

- AC-1 `go-md2man` is pinned in `registry/tools.toml` with its source and version, and `govulncheck` passes with it; evidence: the registry entry and the gate output
- AC-2 `go generate` writes the man page with `cobra/doc` from the command tree, covering every command, flag and exit code that `wskit --help` shows; evidence: a test that compares the page's command and flag list with the command tree
- AC-3 CI fails when the committed page differs from a fresh generation; evidence: the staleness check failing on a changed help string
- AC-4 The staged release installs the page where `man` finds it on Linux and macOS; evidence: a staging test that lists the installed path for each OS
- AC-5 A person runs `man wskit` after a staged install and reads the commands and exit codes of that version; evidence: the staging test transcript (journey)
