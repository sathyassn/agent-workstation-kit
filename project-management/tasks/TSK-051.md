# TSK-051: Claude instructions route and guided trust steps

## Description

Set Claude Code's instructions route so a session in a project inside a workspace reads the workspace AGENTS.md without the "external imports" approval prompt, and make the Codex folder-trust prompt and this route guided steps (learnings batch 4, 2026-11-23). In worktrees, a parent `CLAUDE.md` that imports `@AGENTS.md` triggers the prompt, and no setting suppresses it. Tested on a Linux workstation: setting the user-scope option `pluginConfigs.cc-plugin-agents-md@builtin.options.instructionFiles` to `claude-md-and-agents-md` in every Claude config home, and removing the `@AGENTS.md` import from the workspace-root `CLAUDE.md`, gives the session the workspace AGENTS.md with no prompt. Project settings ignore this option, so it is set at user scope only. Non-goal: the CodeFlow scaffold change, which CodeFlow tracks.

## Outcome

After this merges, an agent session started in any project or worktree has the workspace instructions in context with no approval prompt, on every Claude config home the kit manages, and the person can follow the Codex trust and Claude route steps from the docs.

## Deliverables

- the setting and its check: `internal/units/agentsettings/` (Claude config homes), the doctor check (EPC-022)
- the default and its reason: `registry/presets.toml`, `registry/sources.toml`
- guided docs: the agent-settings docs page, with screenshots from TSK-049; `CHANGELOG.md`

## Acceptance Criteria

- AC-1 The agent-settings unit sets `pluginConfigs.cc-plugin-agents-md@builtin.options.instructionFiles = claude-md-and-agents-md` at user scope in every Claude config home, including each agent-manager profile's home, on by default and shown in `plan` with its reason; revert restores each file exactly; evidence: tests with several config homes
- AC-2 The doctor reports a config home without the setting, and a parent `CLAUDE.md` in a configured code root that imports `@AGENTS.md`, with the fix; the kit never writes the option at project scope; evidence: doctor fixtures
- AC-3 The docs and the setup hand-over give the Codex folder-trust prompt and the Claude instructions route as guided steps, with numbered steps, the exact value, how to verify (a new session in a child repository shows the workspace AGENTS.md and no prompt) and how to undo, on both OSes, with screenshots from TSK-049; evidence: the docs diff
- AC-4 A person starts a Claude session in a worktree of a project inside the workspace after apply, and the session has the workspace AGENTS.md in context with no external-imports prompt; evidence: a run on a test host, recorded in the PR (journey)
