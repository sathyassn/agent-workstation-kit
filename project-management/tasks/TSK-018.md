# TSK-018: Backup, manifest, intent and restore

## Description

Extend `engine.Tx` with `SetState`, state providers, full manifests (owner, mode, ACLs, extended attributes, digest), intent and restore with validators, and package reverts only through the package manager (T2).

## Outcome

After this merges, every unit change, files and state alike, is restored exactly after a failure.

## Deliverables

- engine: `internal/engine/`
- state providers: `internal/platform/`

## Acceptance Criteria

- AC-1 Restore returns files and state to the manifest, including ACLs and extended attributes where supported; evidence: tests
- AC-2 Recovery never restores package-database files; evidence: tests
