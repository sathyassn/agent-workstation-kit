# TSK-018: Backup, manifest, intent and restore

## Description

Extend `engine.Tx` with `SetState`, state providers, full manifests (owner, mode, ACLs, extended attributes, digest), intent and restore with validators, and package reverts only through the package manager (T2).

## Outcome

After this merges, every unit change, files and state alike, is restored exactly after a failure.

## Deliverables

- engine: `internal/engine/`
- state providers: `internal/platform/`

## Acceptance Criteria

- AC-1 Restore returns files and state to the manifest, including ACLs and extended attributes where supported; evidence: tests
- AC-2 Recovery never restores package-database files; evidence: tests
- AC-3 Once these manifests exist, the TSK-013 refusal of targets with ACLs or extended attributes (except macOS `com.apple.provenance`) is lifted, and a file carrying them is changed and reverted with its content and metadata identical; a filesystem without ACL or xattr support records them as absent; evidence: tests on Linux and macOS (moved from TSK-041)
- AC-4 The serialised SetState contract check signals when the second call has entered SetState before its probe wait starts, and its doc comment says why proving absence needs a time bound (follow-up from #35); evidence: the test and the comment
- AC-5 A unit changes a file with ACLs and xattrs and a hostname value, the run is killed after the change, and the next start restores both exactly; evidence: an engine kill-and-resume test (journey)
