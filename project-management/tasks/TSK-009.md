# TSK-009: CLI skeleton, typed constants and unit catalog

## Description

Build the `wskit` command tree with cobra and fang, the shared verbs and flags declared once, typed constants for unit IDs, verbs, stages, scopes, statuses and exit codes, the event type and sink interface, and the generated unit catalog (T1a).

## Outcome

After this merges, contributors can add a unit to the catalog and get its commands, constants and docs without editing core code.

## Deliverables

- command tree: `cmd/wskit/`, `internal/cli/`
- events and sink: `internal/engine/`, `internal/ui/`
- catalog: `internal/units/catalog_gen.go`

## Acceptance Criteria

- AC-1 `wskit --help`, `wskit version` and completions for bash, zsh and fish are generated; evidence: golden tests
- AC-2 Exit codes match SPC-001, including 6 for drift; evidence: tests
- AC-3 `--stage` exists and `--scope` does not; evidence: CLI tests
- AC-4 `Tx.Emit` never blocks, and a full queue coalesces only progress events; evidence: tests
