# TSK-041: Full metadata backup for ACLs and extended attributes

## Description

Back up and restore a target's full metadata, its ACLs and extended attributes, so units can manage paths that carry them. Until this lands, the engine refuses any target with an ACL or extended attribute (the #33 security review, TSK-013), except the `com.apple.provenance` attribute macOS adds to files ordinary processes write. This task replaces that refusal with a backup that keeps the metadata and a restore that puts it back exactly. Non-goal: SELinux or AppArmor labels beyond what the extended attributes carry.

## Outcome

After this merges, a unit can change a file that has ACLs or extended attributes on Linux or macOS, and revert restores the file with the same metadata.

## Deliverables

- backup and restore of ACLs and extended attributes: `internal/engine/` (the backup and restore paths and the metadata helpers per OS)
- the refusal removed or narrowed: `internal/engine/fsroot.go` and the per-OS metadata files
- tests and docs: engine tests per OS, ADR 0005 section 5 (backup format), `CHANGELOG.md`

## Acceptance Criteria

- AC-1 A backup records every extended attribute and, on macOS, the ACL read through `fgetattrlist`, and a POSIX ACL on Linux through its extended attributes; the backup manifest lists them and is fsynced before the intent, as the rest of the backup is; evidence: tests per OS
- AC-2 Restore writes the content first, then the extended attributes and ACLs, and verifies them against the backup; a mismatch fails the restore closed (exit 4) with the intent left unfinished; evidence: tests with a fake that drops an attribute
- AC-3 Apply then revert of a file with ACLs and extended attributes leaves the file byte-identical and metadata-identical; evidence: tests on Linux and macOS
- AC-4 A filesystem that does not support extended attributes or ACLs is reported once and treated as having none, never as an error; evidence: a test with a fake filesystem
- AC-5 A unit changes a file that carries an ACL and an extended attribute, then reverts it, and the file's content and metadata match the original; evidence: the test transcript (journey)
