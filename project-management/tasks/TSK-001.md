# TSK-001: Restore the CodeFlow model-evaluation skill

## Description

The CodeFlow full-tier scaffold was committed without its model-evaluation
skill, because the skill's eval case IDs start with `sk-`, which CodeFlow's
own pre-commit secret scan refuses. Once CodeFlow fixes that upstream (its issue 923), run
`codeflow update` to restore the skill and remove the interim ignore lines.

## Outcome

After this merges, agents in this repository can use CodeFlow's
model-evaluation skill like every other full-tier skill.

## Deliverables

- restored skill: `.agents/skills/cf-evaluate-model/`, `.claude/skills/cf-evaluate-model/`
- removed ignore lines: `.gitignore`
- changelog note: `CHANGELOG.md`

## Acceptance Criteria

- AC-1 When the CodeFlow release that fixes the eval case IDs is installed, `codeflow update` restores the skill and the commit passes the pre-commit secret scan; evidence: the commit
- AC-2 The interim ignore lines and their comment are gone from `.gitignore`; evidence: the diff
