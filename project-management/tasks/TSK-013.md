# TSK-013: Minimal engine with durable intent and supervision

## Description

Build `engine.Tx` with file backups, atomic writes, receipts, the locks in their order, durable intent with the one recovery rule, OS containment per apply with acknowledged identities, bounded shutdown, the staged-binary check, the one root-approval check before any lock, and the `cmd/agentctl` skeleton (T1c).

## Outcome

After this merges, a unit's file changes are backed up, receipted and recovered after any crash, and root runs only from the staged binary.

## Deliverables

- engine: `internal/engine/`
- containment adapters: `internal/platform/linux/`, `internal/platform/darwin/`
- sudo helper skeleton: `cmd/agentctl/`

## Acceptance Criteria

- AC-1 A kill at every boundary ends, after the next start, in a restored then reapplied state; evidence: fault-injection tests
- AC-2 A restart empties the containment within its bound or exits 4 without taking the lock; evidence: tests
- AC-3 As root, `wskit` exits 5 unless it is the staged binary; evidence: tests and the CI staging job
- AC-4 A package-manager transaction is never killed by cancel or grace; evidence: tests
