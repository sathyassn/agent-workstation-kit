# TSK-006: Day-zero bootstrap script

## Description

Write `scripts/bootstrap.sh`, a few lines of POSIX sh that download the pinned `wskit` for the detected OS and CPU, verify the checksum file's signature and the binary's checksum with system tools, and run it for the setup user without root. Refuse an unsupported OS or CPU with the reason.

## Outcome

After this merges, a person on a fresh supported machine can install a verified `wskit` with one command.

## Deliverables

- script: `scripts/bootstrap.sh`
- tests: `tests/`
- runbook update: `docs/runbooks/`

## Acceptance Criteria

- AC-1 When the signature or checksum does not verify, the script stops before running the binary; evidence: shell tests with a fake download
- AC-2 The script passes `shellcheck` in POSIX mode and never uses `sudo`; evidence: CI
- AC-3 On an unsupported OS or CPU it exits with the reason; evidence: tests
