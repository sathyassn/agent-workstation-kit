# TSK-050: Local person-name warning on changed prose

## Description

Warn a contributor, before they push, when changed prose looks like it contains a person's name, using statistical person-name detection (operator decision, 2026-11-23). Pattern detectors and the identity check (TSK-007, TSK-008) cannot recognise other people's names. This check runs locally only, before push, warn-only, on changed prose lines only (docs, code comments, commit messages and PR text), with Presidio's analyzer and spaCy's small English model and a short time budget of about two to three seconds; over budget it skips with a note and never delays or blocks the push. It does not run in CI unless later evidence shows it earns it. It is optional, configurable and uses the tracked exemption records from TSK-007. Non-goal: blocking, and scanning code or data files.

## Outcome

After this merges, a contributor who writes a real person's name into a doc or comment sees a warning with the file and line before pushing, and the push is never held up by the check.

## Deliverables

- the check and its wiring into the local pre-push run: `tests/` (a helper the public-safety scan calls when the check is enabled)
- pinned versions of `presidio-analyzer`, spaCy and `en_core_web_sm` with their sources and checksums: `registry/tools.toml`
- docs: `docs/13-public-release-checklist.md`, `CHANGELOG.md`

## Acceptance Criteria

- AC-1 The check reads only the changed prose lines of the push (Markdown and text docs, code comments, commit messages and a PR body file when given) and warns with the file, line and the rule name, never the matched text; it never fails the push; evidence: tests with names in changed and unchanged lines
- AC-2 It uses `presidio-analyzer` with `en_core_web_sm` (never `en_core_web_lg` by default), pinned in `registry/tools.toml` with source and checksum; evidence: the registry entries and an install test
- AC-3 A time budget (default about 2.5 seconds) bounds the check; over budget it stops, prints one note saying it was skipped, and the push continues; when the tools are not installed it prints one note and continues; evidence: tests with a slow fake analyzer and with the tools absent
- AC-4 The check is optional and configurable (on locally when the tools are present, warn-only, not in CI by default), and applies the tracked exemption records from TSK-007, listing each exemption it used; evidence: tests of the configuration
- AC-5 It runs the same on Linux and macOS; evidence: tests on both OSes
- AC-6 A contributor adds a sentence naming a real-looking person to a doc and pushes; they see one warning with the file and line, and the push completes; evidence: the test transcript (journey)
