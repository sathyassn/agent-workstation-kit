# TSK-027: Tunnel supervisor job and readiness

## Description

Add the tunnel supervisor job (a systemd user unit or a launchd agent job) that acknowledges the deadline before `ssh` starts, the forward-ready check (the debug line plus the bound listener), the callback-delivered signal, the time limit, `close` and `status`.

## Outcome

After this merges, a person can run `wskit tunnel open` and know the forward closes at its time limit even if the client dies.

## Deliverables

- supervisor and readiness: `internal/units/browsertunnel/`, `internal/platform/`

## Acceptance Criteria

- AC-1 The job stops `ssh` at the deadline after the client process is killed; evidence: tests on Linux and macOS
- AC-2 A port in use on either address family is refused; evidence: tests
- AC-3 A faked readiness line does not open the browser; evidence: tests
- AC-4 A crash before the acknowledgement leaves a record that the next run removes; evidence: fault-injection tests
