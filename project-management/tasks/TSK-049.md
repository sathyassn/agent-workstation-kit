# TSK-049: Guided manual steps with sanitised screenshots

## Description

Give every manual step the kit cannot automate a sanitised screenshot, so the guided docs and hand-overs show the exact panel, field and value. The steps come from learnings batch 4 and earlier: the agent manager's terminal-shell setting, macOS Screen Sharing mode and curtain, the NoMachine client and server options, the Docker Desktop and OrbStack memory settings, Passwords and Keys on Linux, the Spotlight privacy list in System Settings, and the Codex folder-trust prompt. Screenshots come from the real UI (through computer use, or the agent manager's own screenshot support) and are sanitised before they enter the public repository. Non-goal: the step text itself, which each owning task writes.

## Outcome

After this merges, a person following a hand-over sees a cropped, sanitised screenshot of each manual step on each OS where it differs, and no screenshot reveals a person, account, device or network.

## Deliverables

- screenshots with alt text: `docs/images/manual-steps/` (provisional; follows the docs structure)
- the sanitising checklist and naming rule: `docs/standards/screenshots.md` (new)
- links from each guided step's docs page and hand-over

## Acceptance Criteria

- AC-1 Each manual step named in the description has a screenshot per OS where the step differs, cropped to the relevant panel, with alt text that states what the panel shows and the value to enter; evidence: the docs diff and a list mapping each step to its files
- AC-2 Every screenshot is sanitised: personal names, accounts, emails, device and host names, paths with real user names, tailnet details and tokens are blurred or replaced with the neutral examples; the review checks each image visually and records it in the PR; evidence: the review record
- AC-3 The public-safety scan covers screenshot file names and alt text, and the file names follow the naming rule (step and OS, no personal or host names); evidence: the scan output
- AC-4 The screenshots checklist says how to take, crop, sanitise and name a screenshot, and is linked from the engineering standard; evidence: the docs diff
- AC-5 A person follows the agent-manager terminal-shell hand-over on macOS and on Linux using only the docs and the screenshots, and the verify step passes; evidence: a walkthrough by a fresh reader, recorded in the PR (journey)
