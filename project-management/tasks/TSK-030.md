# TSK-030: Agent-work ceiling and early OOM

## Description

Build the `resource-limits` unit's Linux ceiling: a dedicated agent-work slice with MemoryHigh, MemoryMax, CPUWeight and CPUQuota sized by the reserve formula (ADR 0005 section 7a), with explicit values as labelled overrides, applied to the subtree where agent work runs, plus systemd-oomd with pressure settings or a documented fallback. The frozen script's reserve formula from TSK-034 is the behaviour reference.

## Outcome

After this merges, agent work on a Linux machine runs under a memory and CPU ceiling with early OOM handling, applied and reverted by `wskit`.

## Deliverables

- unit: `internal/units/resourcelimits/`
- adapter: `internal/platform/linux/`

## Acceptance Criteria

- AC-1 The ceiling follows the reserve formula, computed from RAM and cores at run time: reserve = fixed part + 2% of RAM, MemoryMax = RAM - reserve, MemoryHigh = MemoryMax - min(10% of MemoryMax, 8 GiB), and the CPU reserve and quota; an explicit value overrides the formula and `plan` labels it; evidence: tests at 16, 60, 128 and 512 GiB
- AC-2 Apply then revert leaves the slice files and oomd settings byte-identical to before; evidence: tests in a test root
- AC-3 Work started outside the slice, and a user-level override that outranks it, are reported by `verify`; evidence: tests
