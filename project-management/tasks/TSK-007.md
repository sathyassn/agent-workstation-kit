# TSK-007: Keyed matching that fails closed

## Description

Match personal names and private network names in the public scan by keyed HMAC, with the key in an untracked local file and a CI secret, and fail closed when the key is missing or the file listing fails or is empty. This is a security change and needs a cross-lineage review.

## Outcome

After this merges, maintainers can scan for private names without the rule file containing or revealing them.

## Deliverables

- scanner: `tests/check_public_release.py`
- tests: `tests/`
- CI wiring: `.github/workflows/`

## Acceptance Criteria

- AC-1 When the key is missing in CI, the scan fails; evidence: a test
- AC-2 When the file listing fails or is empty, the scan fails; evidence: a test
- AC-3 The rule file holds only HMAC digests; evidence: review and a test
