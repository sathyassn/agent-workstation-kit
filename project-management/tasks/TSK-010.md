# TSK-010: Frozen-code fixes for apply, host lock and remote desktop

## Description

Fix three live problems in the frozen Python and shell: `fleetctl run --apply` exits 2 and prints the executor commands; the macOS host lock moves under a root-owned folder so macOS root scopes run; and `install-local-deb-linux.sh` refuses NoMachine unless the firewall is active.

## Outcome

After this merges, macOS root scopes run again, and nobody can apply a phase or install NoMachine outside the safeguards.

## Deliverables

- fixes: `scripts/fleetctl.py`, `scripts/execute-setup.py`, `scripts/install-local-deb-linux.sh`
- docs: the pages that show `fleetctl run --apply`
- changelog: `CHANGELOG.md`

## Acceptance Criteria

- AC-1 `fleetctl run ... --apply` exits 2; evidence: a test, and a repository check that fails if a doc shows it again
- AC-2 On macOS, a root scope takes the host lock under `/Library/Application Support/agent-workstation-kit/run/`; evidence: a test on a macOS runner
- AC-3 Installing NoMachine with the firewall inactive is refused; evidence: a test
- AC-4 A person who runs `fleetctl run PROFILE PHASE --apply` is stopped with exit 2 and shown the executor commands to preview and apply that phase's scope instead; evidence: tests/test_fleetctl.py (journey)
