# EPC-010: Resources unit

## Summary

The machine-wide resource ceiling for agent work (ADR 0005 section 7a), moved early because a pilot host kept thrashing. It is the first unit right after T2, which provides the root baseline it needs. Pilot hosts are covered meanwhile by the frozen script fix.

## Outcome

After this merges, agent work runs under one ceiling with a reserve, early OOM handling and a `/tmp` policy, admitted by pressure.

## Deliverables

- unit: `internal/units/resourcelimits/`
- defaults: `registry/presets.toml` (the defaults table, principle 13)
- page: `docs/`

## Acceptance Criteria

- AC-1 An agent-work cgroup ceiling applies MemoryHigh and MemoryMax as shares of RAM to the subtree where agent work runs, not the whole user slice; evidence: tests
- AC-2 systemd-oomd, or a documented equivalent, is enabled with pressure settings for that subtree; on macOS, launchd and taskpolicy equivalents apply, with the memory-ceiling gap recorded; evidence: tests
- AC-3 Swap and zram are sized as shares of RAM, `/tmp` is kept disk-backed or caches are redirected off tmpfs, and disk free-space floors are checked with cache-cleanup guidance; evidence: tests
- AC-4 Each setting applies its best-practice default when unset, shows it in `plan` with its reason and source, and every opt-out works (principle 13); evidence: tests
- AC-5 Admission reads pressure data, not fixed numbers; evidence: tests
- AC-6 For each unit this epic owns, standalone apply and revert tests pass, and an interrupted revert resumes to the previous receipt; evidence: unit tests and the stress-run log
- AC-7 Each PR in this epic carries tests, an adversarial review of code and docs, an interruption stress run, a docs-only walkthrough by a fresh agent and a changelog entry; evidence: the PR bodies
