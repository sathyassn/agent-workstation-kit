# EPC-032: Fleet adoption

## Summary

Existing hosts and fleets move to `wskit` (ADR 0005 section 2b).

## Outcome

After this merges, existing hosts are converged, fleets use `wskit fleet`, and fleet scripts are retired.

## Deliverables

- convergence runbook: `docs/runbooks/`
- fleet migration guide: `docs/`

## Acceptance Criteria

- AC-1 An existing host gets an as-found baseline at its first convergence run, with earlier hand changes recorded, not reverted; evidence: a run record
- AC-2 A fleet's VPN script is replaced by `wskit vpn` plus fleet values; evidence: the fleet migration record
- AC-3 Each PR in this epic carries tests, an adversarial review of code and docs, an interruption stress run, a docs-only walkthrough by a fresh agent and a changelog entry; evidence: the PR bodies
