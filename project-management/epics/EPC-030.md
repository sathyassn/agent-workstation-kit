# EPC-030: Acceptance for 1.0.0

## Summary

The 1.0.0 release criteria (ADR 0005, acceptance).

## Outcome

After this merges, the owner can release 1.0.0 because its criteria hold on one Linux and one macOS machine.

## Deliverables

- evidence: `docs/maintenance/releasing.md`, the release PR

## Acceptance Criteria

- AC-1 An agent conducts one clean setup on each OS from the interview to the stable point, with one interrupt it diagnoses and resumes; evidence: run records
- AC-2 `revert --to baseline` passes the match digest; evidence: run records
- AC-3 The doctor is green and a docs-only walkthrough passes; evidence: run records
- AC-4 Acceptance covers both account topologies, and a `developer` run on a portable Mac; evidence: run records
- AC-5 Each PR in this epic carries tests, an adversarial review of code and docs, an interruption stress run, a docs-only walkthrough by a fresh agent and a changelog entry; evidence: the PR bodies
