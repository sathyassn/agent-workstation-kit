# EPC-007: VPN unit

## Summary

One generic  unit for every fleet, with provider profiles and typed destination sources (ADR 0005 sections 2d and 10c).

## Outcome

After this merges, a machine can reach office-only services through a VPN whose destinations are typed config.

## Deliverables

- unit: `internal/units/vpn/`
- page: `docs/`

## Acceptance Criteria

- AC-1 When a destination resolves to a non-global address, it shall be refused; evidence: tests
- AC-2 No address appears in tracked files, output or logs; evidence: tests
- AC-3 The published status file follows one schema enforced by writer and reader; evidence: tests
- AC-4 For each unit this epic owns, standalone apply and revert tests pass, and an interrupted revert resumes to the previous receipt; evidence: unit tests and the stress-run log
- AC-5 The unit arms the dead-man timer (section 6 of ADR 0005) before any route or firewall change; evidence: tests
- AC-6 Each PR in this epic carries tests, an adversarial review of code and docs, an interruption stress run, a docs-only walkthrough by a fresh agent and a changelog entry; evidence: the PR bodies

## Out of scope

- organisation values, which live in a fleet
- plugin and command destination sources (after 1.0.0)

## Affected surfaces and interfaces

- Surfaces: the units named here, their docs pages and their registry entries.
- Units: vpn (the unit catalog, ADR 0005 section 15)
- Depends on: EPC-005, EPC-015 (the dead-man timer)
