# EPC-008: Shell unit

## Summary

The shell baseline as a managed block (ADR 0005 sections 7 and 8).

## Outcome

After this merges, a person or agent gets the kit's shell baseline alongside other tools' blocks, with a prompt option and an agent-shell guard.

## Deliverables

- dotfiles: `dotfiles/`
