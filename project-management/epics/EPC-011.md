# EPC-011: Registry-driven tools unit

## Summary

Most CLIs need no code: a registry entry drives install, verify and uninstall (ADR 0005 section 2e).

## Outcome

After this merges, a person or agent can add or remove a CLI with `wskit tools add|remove` from a reviewed registry entry.

## Deliverables

- unit: `internal/units/tools/`
- entries: `registry/tools.toml`

## Acceptance Criteria

- AC-1 When `wskit tools add TOOL` runs, the machine config shall be updated and the same transaction run; evidence: tests
- AC-2 Support limits show in `plan`, not during apply; evidence: tests
- AC-3 The agy entry installs through the vendor installer, checked by SHA-512 against its manifest, at a pinned version (1.5.14 when planned). The installer appends duplicate PATH exports to `.bashrc`, `.profile` and `.zshrc`, so the entry either backs up those files and removes the duplicates, or installs with `--dir` and manages PATH itself; evidence: tests
- AC-4 agy's token store depends on the session (the keyring in a desktop or agent-manager terminal, a file store over SSH). The sign-in hand-over runs in the context the agents use (the same session type and account), not only documents it, and the doctor checks auth from that context; evidence: tests and the docs page
- AC-5 On Linux, `secret-tool` (Ubuntu `libsecret-tools`), which agent-manager account switching needs, installs with agy and the doctor checks it; evidence: tests
- AC-6 On Linux with `kernel.apparmor_restrict_unprivileged_userns=1`, agy Auto mode needs an AppArmor per-app user-namespace profile (`flags=(unconfined)` plus `userns`) on a root-owned, pinned binary. The entry shows it in preview, applies and reverts it, and documents it; evidence: tests and the docs page
- AC-7 For each unit this epic owns, standalone apply and revert tests pass, and an interrupted revert resumes to the previous receipt; evidence: unit tests and the stress-run log
- AC-8 Each PR in this epic carries tests, an adversarial review of code and docs, an interruption stress run, a docs-only walkthrough by a fresh agent and a changelog entry; evidence: the PR bodies
