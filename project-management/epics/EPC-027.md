# EPC-027: Update watch

## Summary

Update watch (ADR 0005 section 9).

## Outcome

After this merges, maintainers see upcoming tool updates and end-of-support dates before they matter.

## Deliverables

- watch job: `.github/workflows/`, `internal/registry/`

## Acceptance Criteria

- AC-1 Updates are opened as PRs and never merged automatically; evidence: the job's config
- AC-2 The watch checks every link in `registry/sources.toml` for health and staleness and opens PRs to refresh entries; evidence: the job's runs
- AC-3 Each PR in this epic carries tests, an adversarial review of code and docs, an interruption stress run, a docs-only walkthrough by a fresh agent and a changelog entry; evidence: the PR bodies
