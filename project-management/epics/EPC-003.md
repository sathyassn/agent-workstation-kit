# EPC-003: CLI skeleton and contracts

## Summary

T1 builds the `wskit` CLI and the contracts every unit uses (ADR 0005 sections 2b, 3, 4, 15), in milestones T1a to T1c, plus the frozen-code fixes.

## Outcome

After this merges, an agent can run `wskit plan` and `wskit next --json` on a supported machine, units register through the generated catalog, and root steps run only from the staged binary.

## Deliverables

- CLI and conventions: `cmd/wskit/`, `internal/cli/`
- catalog and domains: `internal/units/catalog_gen.go`, `registry/units.toml`
- schema 3 parity, generated types, config layers: `internal/schema/`, `schema/`
- platforms: `registry/platforms.toml`, `internal/platform/`
- planner and next: `internal/planner/`, `internal/conductor/`
- minimal engine: `internal/engine/`
- sudo helper skeleton: `cmd/agentctl/`
- frozen-code fixes: `scripts/fleetctl.py`, `scripts/execute-setup.py`, `scripts/install-local-deb-linux.sh`
- conductor recipe v1 and review rules: `AGENTS.md`

## Acceptance Criteria

- AC-1 When `wskit next --json` runs on a supported machine with an approved plan, it shall return the shape in ADR 0005 section 15.7, with commands as argument arrays; evidence: golden tests
- AC-2 When the Python and Go validators read the same fixture profiles, they shall accept and reject the same ones; evidence: the parity test
- AC-3 When `wskit` runs as root from any path other than the staged path, it shall exit 5; evidence: tests and the CI staging job on Linux and macOS
- AC-4 When the engine is killed during a write, the next start shall find the intent, stop recorded processes, and restore or finish before anything else; evidence: fault-injection tests
- AC-5 When `fleetctl run --apply` is used, it shall exit 2; and macOS root scopes shall run with the host lock under the new root-owned folder; evidence: tests
- AC-6 Unit IDs, verbs, stages, scopes, statuses and exit codes are typed constants; evidence: lint rules and review
- AC-7 Presets resolve for every purpose, tier, OS and form factor; `full` equals the feasible units; skipped units carry reasons; evidence: tests
- AC-8 `--platform` and `--form-factor` work for `plan` and preview and are refused by `apply`; evidence: tests
- AC-9 `--stage` takes the scope ID and there is no `--scope` flag; evidence: CLI tests
- AC-10 Each PR in this epic carries tests, an adversarial review of code and docs, an interruption stress run, a docs-only walkthrough by a fresh agent and a changelog entry; evidence: the PR bodies
