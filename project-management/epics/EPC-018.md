# EPC-018: Fleet commands

## Summary

Fleet management in the same CLI (ADR 0005 section 2b).

## Outcome

After this merges, a fleet maintainer can manage a private fleet of config and records with `wskit fleet`.

## Deliverables

- commands: `internal/cli/`, `internal/fleet/`
- template: `templates/private-fleet/`

## Acceptance Criteria

- AC-1 When a fleet entry duplicates a kit ID or changes a kit field's definition, `fleet validate` shall refuse it; evidence: tests
- AC-2 `fleet lock bump` verifies the release signature and checksum; evidence: tests
- AC-3 Each PR in this epic carries tests, an adversarial review of code and docs, an interruption stress run, a docs-only walkthrough by a fresh agent and a changelog entry; evidence: the PR bodies
