# EPC-013: Packages and runtimes units

## Summary

OS packages and runtimes at exact pins (ADR 0005 sections 3, 9, A1).

## Outcome

After this merges, OS packages and runtimes install at exact pins, with the SSH and remote-desktop install guards.

## Deliverables

- units: `internal/units/packages/`, `internal/units/runtimes/`

## Acceptance Criteria

- AC-1 When a source no longer serves the pin, the install shall stop; evidence: tests
- AC-2 NoMachine and SSH stay masked until released in S5; evidence: tests
- AC-3 For each unit this epic owns, standalone apply and revert tests pass, and an interrupted revert resumes to the previous receipt; evidence: unit tests and the stress-run log
- AC-4 Each PR in this epic carries tests, an adversarial review of code and docs, an interruption stress run, a docs-only walkthrough by a fresh agent and a changelog entry; evidence: the PR bodies

## Out of scope

- none

- Units: packages, packages-brew, packages-pkg, runtimes (the unit catalog, ADR 0005 section 15)
