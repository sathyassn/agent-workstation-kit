# EPC-019: Workloads and agentctl units

## Summary

Workloads and the narrow sudo helper (ADR 0005 sections 3, 7).

## Outcome

After this merges, workloads and the narrow `agentctl` helper are installed with an atomic sudoers rule.

## Deliverables

- units: `internal/units/agentctl/`, `internal/units/workloads/`
- helper: `cmd/agentctl/`

- AC-3 Each PR in this epic carries tests, an adversarial review of code and docs, an interruption stress run, a docs-only walkthrough by a fresh agent and a changelog entry; evidence: the PR bodies
