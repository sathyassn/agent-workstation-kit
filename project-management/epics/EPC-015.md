# EPC-015: SSH and firewall units

## Summary

SSH and firewall under the dead-man timer (ADR 0005 section 6).

## Outcome

After this merges, SSH and firewall changes apply and revert under the dead-man timer on both OSes.

## Deliverables

- units: `internal/units/ssh/`, `internal/units/firewall/`

## Acceptance Criteria

- AC-1 When the connectivity proof is not recorded by the deadline, the step shall be restored; evidence: fault-injection tests
- AC-2 A restore keeps the proven mesh-VPN SSH path; evidence: tests
- AC-3 Disarm is durable and a torn disarm is safe; evidence: tests
- AC-4 For each unit this epic owns, standalone apply and revert tests pass, and an interrupted revert resumes to the previous receipt; evidence: unit tests and the stress-run log
- AC-5 The dead-man timer ships in this epic; until it exists, `ssh` and `firewall` apply and revert are refused; evidence: tests
- AC-6 On macOS, an armed step from an earlier boot is restored at once; evidence: tests
- AC-7 A revert keeps the proven mesh-VPN SSH path and its dependency closure; evidence: tests
- AC-8 On a fresh first install, the mesh-VPN client is installed and enrolled before the firewall and ssh group, so the proof path exists; with remote access off, the group runs with no timer and a console proof; evidence: an end-to-end first-install test
- AC-9 After the group, `next` returns `disarm` before any later root unit; evidence: tests
- AC-10 Each PR in this epic carries tests, an adversarial review of code and docs, an interruption stress run, a docs-only walkthrough by a fresh agent and a changelog entry; evidence: the PR bodies
- AC-11 The firewall unit has an `mdns` setting, `off`, `on` or `on-interfaces` with a list of trusted LAN interfaces, default `off` on work machines, shown in `plan` with its reason and what stops working when off. On Linux: a UFW rule for 5353/udp only on the named interfaces, never on the mesh-VPN interface, and avahi `allow-interfaces` to match with `publish-workstation=no`. On macOS, where mDNSResponder cannot be turned off without breaking the system (a recorded gap), Application Firewall stealth mode and blocked incoming connections for Bonjour-advertising services; evidence: tests per value on both OSes (TSK-038)
