# EPC-015: SSH and firewall units

## Summary

SSH and firewall under the dead-man timer (ADR 0005 section 6).

## Outcome

After this merges, SSH and firewall changes apply and revert under the dead-man timer on both OSes.

## Deliverables

- units: `internal/units/ssh/`, `internal/units/firewall/`

## Acceptance Criteria

- AC-1 When the connectivity proof is not recorded by the deadline, the step shall be restored; evidence: fault-injection tests
- AC-2 A restore keeps the proven mesh-VPN SSH path; evidence: tests
- AC-3 Disarm is durable and a torn disarm is safe; evidence: tests
- AC-4 For each unit this epic owns, standalone apply and revert tests pass, and an interrupted revert resumes to the previous receipt; evidence: unit tests and the stress-run log
- AC-5 Each PR in this epic carries tests, an adversarial review of code and docs, an interruption stress run, a docs-only walkthrough by a fresh agent and a changelog entry; evidence: the PR bodies
