# EPC-029: Organisation units

## Summary

Fleets add their own units without their own tools (ADR 0005 section 2d).

## Outcome

After this merges, a fleet can add constrained declarative units and command sources, through the same engine; plugin executables come after v0.2.0.

## Deliverables

- declarative units and command sources: `internal/engine/`, `internal/units/`
- samples: `testdata/`

## Acceptance Criteria

- AC-1 A sample declarative unit and a sample command source pass apply, revert, an interrupt and a refusal of a write outside declared paths; evidence: tests
- AC-2 Commands run as argument arrays through engine.Tx, with the resolved executable checked against its pinned checksum; evidence: tests
- AC-3 Each PR in this epic carries tests, an adversarial review of code and docs, an interruption stress run, a docs-only walkthrough by a fresh agent and a changelog entry; evidence: the PR bodies
