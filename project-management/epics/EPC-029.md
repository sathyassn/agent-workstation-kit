# EPC-029: Organisation units

## Summary

Fleets add their own units without their own tools (ADR 0005 section 2d).

## Outcome

After this merges, a fleet can add declarative units built from typed operations, through the same engine, after 1.0.0; command steps and plugins come later still.

## Deliverables

- declarative units: `internal/engine/`, `internal/units/`
- samples: `testdata/`

## Acceptance Criteria

- AC-1 A sample declarative unit passes apply, revert, an interrupt and a refusal of an operation outside its declared paths; evidence: tests
- AC-2 Each typed operation maps to an `engine.Tx` call with declared owned paths; evidence: tests
- AC-3 Declarative units use only typed operations (packages, templated files, managed blocks, services, users and groups, checks); command steps are refused; evidence: tests
- AC-4 Each PR in this epic carries tests, an adversarial review of code and docs, an interruption stress run, a docs-only walkthrough by a fresh agent and a changelog entry; evidence: the PR bodies
